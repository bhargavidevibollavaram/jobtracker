\# Job Application Tracker



A web-based Job Application Tracker built using Java, Spring Boot, MySQL, HTML, CSS, and JavaScript.



\## 📌 About the Project



The Job Application Tracker helps users manage and track their job applications in one place.



Users can add job applications and maintain important information such as company name, job role, application status, and application date.



\## 🚀 Features



\- Add new job applications

\- View job applications

\- Track application status

\- Store job application details in MySQL

\- REST API backend using Spring Boot

\- Simple and responsive web interface

\- Persistent database storage
